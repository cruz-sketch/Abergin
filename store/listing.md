# Draft Microsoft Store listing

Category: Developer tools. Suggested price: Free (confirm when submitting).

## English

**Name:** Abergin

**Short description:** A fast Windows terminal with tabs, split panes, SSH,
search, themes, and session restoration.

**Description:** Abergin brings your local shells and SSH sessions into one
focused Windows terminal. Open PowerShell, PowerShell 7, Git Bash, Command
Prompt, or WSL in tabs and split panes. Save SSH connections, search terminal
output, choose a theme and font, and resume your workspace after restarting.
Shell availability depends on what is installed on your device.

**What's new:** In-window settings, terminal font selection, and search that
works across keyboard layouts. New tabs open in the active pane's directory.

**Certification notes:** Abergin is a full-trust terminal. It launches
user-selected shell executables through Windows ConPTY and starts the Windows
OpenSSH client only when the user opens an SSH connection. The `runFullTrust`
capability is required for these functions. The MSIX build does not modify
Explorer context-menu registry entries.

## Українська

**Назва:** Abergin

**Короткий опис:** Швидкий термінал для Windows із вкладками, розділеними
панелями, SSH, пошуком, темами та відновленням сеансів.

**Опис:** Abergin об’єднує локальні оболонки та SSH-сеанси в одному вікні.
Відкривайте PowerShell, PowerShell 7, Git Bash, Command Prompt або WSL у
вкладках і розділених панелях. Зберігайте SSH-підключення, шукайте вивід
термінала, обирайте тему й шрифт та відновлюйте робочий простір після
перезапуску. Доступність оболонок залежить від того, що встановлено на
комп’ютері.

**Що нового:** Налаштування у вікні, вибір шрифту й пошук, який працює з
різними розкладками клавіатури. Нові вкладки відкриваються в директорії
активної панелі.
